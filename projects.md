# Projects

This is an overview of my projects. It also provides additional information to papers or talks.

## Find your Figure
[Find your Figure](https://github.com/kuehnram/FindYourFigure) is a web application to find the name of a rhetorical figure hidden in a German text. It has a very structured input method but also provides a free text field to chat with an LLM within a RAG pipeline based on the [GRhOOT ontology](https://ramonakuehn.de/grhoot).

## Survey
This survey investigates datasets and computational detection approaches towards lesser-known/lesser-investigated rhetorical figures. For details and additional material click [here](https://ramonakuehn.de/survey).

## Ontologies

### GRhOOT Ontology
The [GRhOOT Ontology](https://ramonakuehn.de/grhoot) is an ontology for rhetorical figures in the German language.

### ESTHER Ontology
The [ESTHER ontology](https://ramonakuehn.de/esther) of English rhetorical figures is the adaption of the German GRhOOT ontology to English.

### Multilingual Ontology
This multilingual ontology combines the Serbian RetFig, the German GRhOOT, and the English Ploke ontology. It highlights the cultural and linguistic differences, while combining the formal structure of RetFig and Serbian with cognitive affinities of the Ploke ontology.


## Wiktionary Parser for German Antonyms
Due to the lack of language resources in German, I wrote a [parser to extract antonmys from the German Wiktionary](https://github.com/kuehnram/Wiktionary_Parser_German_Antonyms). It was part of the paper "Hidden in Plain Sight: Can German Wiktionary and Wordnets Facilitate the Detection of Antithesis?"

## StrucTree
[StructTree](https://github.com/kuehnram/StrucTree) (a small hobby project) is a parser for XML and JSON files that shows the structure of the file similar to the Linux tree command. It is very helpful to generate LaTeX code from it for publications.
